# 出片流程耗时基线 & 换云端配音的收益（2026-10-16 估算）

> 口径：一条标准带货口播片（8 句 / 约 32 秒成片 / 14 镜 / 约 250 字），**机器时间**，不含等灿爹拍板。
> 数据依据：`koubo-ad-video/SKILL.md` §各环节耗时基线（2026-09-23 实测）＋ F5-TTS MLX 比 CosyVoice CPU 快约 3 倍（2026-10-09 定为默认产线）＋ pipeline 实测「复用配音 94 秒出片 / 含卷播+fx 全流程 154s」＋ 坑位 #172 基线（70 句 / 26 分钟 ≈ 22s/句）。

## 一、现状：各环节耗时（本地 F5 配音）

| 环节 | 耗时 | 占比 | 能否并行 |
|---|---|---|---|
| 文案三闸门（合规 / 错别字 / 语义） | 1.5 分 | 9% | 否（等你拍板） |
| 素材语义匹配 + 分镜规划 + 配额自检 | 2.5 分 | 15% | 是 |
| 生新图（复用为主，补 4–6 张） | 3 分 | 18% | 是（云端并行） |
| 抠图分层（hero 分层，本地 Vision） | 1 分 | 6% | 是 |
| **配音（F5 合成 + polish）** | **3 分** | **18%** | **否（独占内存）** |
| whisper 逐字转写 + 拼音强制对齐 | 1 分 | 6% | 否（抢内存） |
| 渲染（卷播 → 底片 → fx → 粒子） | 2.5 分 | 15% | 否 |
| 质检 14 项 + 真峰值补刀 | 1.5 分 | 9% | — |
| 归档 + 出标题 | 1 分 | 6% | — |
| **合计** | **约 17 分** | | |

历史对照（CosyVoice CPU 时代）：同一档片子配音 **6 分 46 秒**，占总机器时间 12 分钟的 **55%**。
换 F5 后配音降到约 3 分（占 18%）——**所以「配音很慢」这个印象，一半是 F5 之前的旧账**。

## 三、比省时间更值钱的三件事

1. **8GB 内存解放**。本地配音是内存杀手：一旦吃紧（swap 上涨、Pageins 暴涨），单段掉 4–8 倍。换云端后：
   - 配音不再需要独占内存 ⇒ 可与其他环节**并行**（现在必须全流程串行等它）
   - 不必开工前跑 `preflight.py` 关程序（实测关 QQ 浏览器能提速 3 倍，说明内存多紧张）
2. **翻车风险归零**。本地配音最怕的就是「跑着跑着变慢」；云端不存在这个失败模式。
3. **电脑可以正常用**。现在配音那几分钟 8GB 机器基本被占死；换云端后本地只做渲染。

## 四、★能不能连 whisper 那一步一起省掉？—— 能，但要改造

**查证结论（2026-10-16）**：MiniMax 支持 **词级时间戳**。

```
subtitle_enable : true
subtitle_type   : "sentence" | "word" | "word_streaming"   # 默认 sentence
```

- 2.8 / 2.6 / 02 / 01 **全系列支持**，仅**非流式**有效（`subtitle_enable` 在流式下无效）
- 时间戳通过 **POST speech/create-mp3 的返回体** 或 **流式 done 事件** 拿到；MiniMax **不存储**时间戳 ⇒ 轮询 `GET speech/audioId` 或 replyUrl 回调只能拿到 `has_srt` 标记，拿不到时间戳本身

⇒ 拿到 word 级时间戳后，本地 **whisper 逐字转写 + 拼音强制对齐**（约 1 分）理论上可整段省掉。
**但需要改流水线**：`mk_tokens_f5.py` 现在吃的是 whisper + `align_vo.py` 产物（`vo_mapped.json`），要改成能直接吃 provider 时间戳格式，并保留多音字侧车（`.poly.json`）的语义。**工作量约半天**。

不改也能用 —— 只省配音那 3 分，字幕链路照旧走 whisper。

## 五、诚实边界（别高估）

- **音色要重新克隆**：MiniMax 与 F5/CosyVoice 是不同模型，音色必然有差异。已发过片的系列感可能断裂 —— 若要保平滑，先试 CosyVoice（同源）。
- **品牌名读法要调**：「21金维他」「VORSE」这类，MiniMax 与 F5 的读法不同，需要实测后决定是否写 `pronunciation_dict`。
- **「等灿爹拍板 + 返工重渲」是体感时间的大头**（历史实录：单条因音色返工渲了 5 遍）。云端**不影响**这部分，别指望它把整体体感砍一半。
- **成本可忽略**：一条 250 字，¥0.02–0.07。真花钱的是**建音色**（MiniMax ¥9.9/个；阿里托管价）。

## 二、MiniMax 参数速查

接口：同步 HTTP / WebSocket（短句、实时）；异步（长文本，单次最长 5 万~100 万字符）。

### `voice_setting`
| 参数 | 说明 |
|---|---|
| `voice_id` | 音色 ID |
| `speed` | 语速，范围 **[0.5, 2.0]**，默认 1.0 |
| `vol` | 音量，(0.0, 10.0] |
| `pitch` | 音高，[-12, 12] |
| `emotion` | `happy` `sad` `angry` `fearful` `disgusted` `surprised` `calm` `whisper`（**2.8 不支持 whisper**）。★ **整段只认第一个情绪标签** |
| `text_normalization` | **带货文案必开 `true`** —— 改善数字读法（略增延迟） |
| `language_boost` | 可设 `Chinese`，提升中文/方言质量 |
| `latex_read` | 读 LaTeX 公式（仅中文） |

### `pronunciation_dict`（修多音字/生词）
```
["Yan Shaofei/(yan4)(shao3)(fei1)", "omg/oh my god"]
```
中文声调用数字：1 声=1、2 声=2、3 声=3、4 声=4、轻声=5。
文本内也可直接写 IPA 或拼音：`(lɪv)`、`这是(he2)平`、`去街市買啲(sung3)`。

### `timbre_weights`（混音色）
最多混 4 个音色，`weight` 范围 [1, 100]，越高越像该音色。

### `voice_modify`（调音色质感）
| 参数 | 范围 | 效果 |
|---|---|---|
| `pitch` | [-100, 100] | 低→低沉，高→明亮 |
| `intensity` | [-100, 100] | 低→刚劲有力，高→轻柔 |
| `timbre` | [-100, 100] | 低→浑厚，高→清脆 |

### 音频输出
`format`（mp3 / pcm / flac / wav）、`sample_rate`（默认 32000）、`bitrate`（默认 128000）、`channel`（默认 1 单声道）。

### 语气词标签（仅 `speech-2.8-hd` / `speech-2.8-turbo`）
```
(laughs) (chuckle) (coughs) (clear-throat) (groans) (breath) (pant)
(inhale) (exhale) (gasps) (sniffs) (sighs) (snorts) (burps)
(lip-smacking) (humming) (hissing) (emm) (whistles) (sneezes)
(crying) (applause)
```
这些是**文本的一部分**，不是 `emotion` 参数。

## 三、停顿规则 · MiniMax 官方口径

| 方式 | 说明 |
|---|---|
| `<#x#>` | x 秒，范围 [0.01, 99.99]，最多两位小数 |
| 约束 1 | **必须夹在两个「可发音文本片段」之间**（不可贴行首/行尾） |
| 约束 2 | **不可连续使用**（两个标记挨着，第二个可能被丢） |
| 换行符 | **段落切换**，会额外带来长间隔 |
| 逗号 | 模型自带约 0.2s 微停 |
| 省略号 `……` | 主要思想间的呼吸停顿（约 0.5s） |

**字符密度阈值（防截尾）：**

| 片段时长 | 中文字符上限 | 目标语速 |
|---|---|---|
| 5 秒 | 15–17 字 | 3.2 字/秒 |
| 10 秒 | 30–34 字 | 3.3 字/秒 |
| 15 秒 | 45–50 字 | 3.3 字/秒 |

超出 → 尾字截断 / 句中呼吸被截 / 累积音高漂移。
**句末必须加标点**，否则可能丢最后一个音节。

## 三·补、★ 阿里系（CosyVoice / Qwen-Audio）用 SSML，语法与 MiniMax 完全不通用

> 2026-10-16 查证。**两家的停顿标记不能互抄，粘错会被当文字念出来或直接报错。**

| 模型 | 停顿写法 | 生效位置 |
|---|---|---|
| MiniMax 全系 | `<#0.35#>` | 文本内，直接生效 |
| CosyVoice v3.5 / v3 / v2 | `<break time="350ms"/>` | **仅 SDK / WebSocket（`enable_ssml:true`）** |
| qwen-audio-3.0-tts-plus / flash、qwen-audio-3.1-tts-flash | `<break time="350ms"/>` | 同上 |

**支持 SSML 的模型白名单**：`qwen-audio-3.1-tts-flash`、`qwen-audio-3.0-tts-flash`、`qwen-audio-3.0-tts-plus`、`cosyvoice-v3.5-flash`、`cosyvoice-v3.5-plus`、`cosyvoice-v3-flash`、`cosyvoice-v3-plus`、`cosyvoice-v2`。
**音色限制**：仅复刻音色，以及音色列表中标注支持 SSML 的系统音色。
**接口限制**：Java SDK ≥2.20.3 / Python SDK ≥1.23.4 的非流式与单向流式；WebSocket 需 `enable_ssml=true` 且只能发一次 `continue-task`。
→ **控制台在线体验页里没有 SSML 开关，试听阶段直接粘纯文本**（阿里系自带断句已经不错），要精细控点就等接 API。

## 四、自然度参考（第三方口径，仅供横向参考）

- **Artificial Analysis TTS Arena ELO**：MiniMax Speech 2.8 HD ≈ **1164**；ElevenLabs Eleven v3 ≈ 1178 → 同一梯队。
- **中文横评（旁白情绪 / 断句 / 呼吸感，满分 10）**：
  - MiniMax Audio **9.5 / 9.0 / 9.0** —— 情绪内容首选，「长句不会匀速平铺」「停顿过渡自然无拼接感」
  - ElevenLabs 中文 **6.0 / 6.5 / 6.5** —— 中文短句停顿偏生硬
  - 讯飞 7.0 / 9.0 / 7.0 —— 正式旁白强，情绪弱
- **主观实测反馈**：语气词「嗯/呢」的停顿、犹豫、呼吸能还原；连文本里的「轻轻叹了口气」都能转成一声极轻的鼻息。
- **短板**：纯语音合成，没有字幕/角色分段的配套功能，长篇要自己切段。

⚠️ 以上都是别人的耳朵。**你自己的参考音频 + 你自己的文案，只能自己听。**

## 六、建音色的硬约束（官方《声音复刻》2026-10-14 版口径）

### ★★ 音色绑定模型，不能跨模型用

> 官方原话：**Qwen-Audio-TTS / Qwen-Audio-Realtime / CosyVoice 的复刻音色在创建时绑定到 `target_model`，不能跨模型使用。如需让多个模型使用同一段音频的声音，应为每个模型分别创建音色。**

⇒ 做三家 A/B 对比，必须**用同一段参考音频建三次音色**。没有"建一次到处用"这回事。

**支持模型**（华北2 北京）：Qwen-Audio-TTS `qwen-audio-3.1-tts-flash` / `qwen-audio-3.0-tts-plus` / `qwen-audio-3.0-tts-flash`；CosyVoice `v3.5-plus` / `v3.5-flash` / `v3-plus` / `v3-flash` / `v2`；MiniMax `speech-2.8-hd` / `speech-02-hd` / `speech-2.8-turbo` / `speech-02-turbo`。

### 参考音频要求（Qwen-Audio-TTS / CosyVoice）

| 项 | 要求 |
|---|---|
| 格式 | WAV（16-bit）、MP3、M4A |
| 时长 | **推荐 10–20 秒，最长 60 秒** |
| 大小 | ≤ 10 MB |
| 采样率 | ≥ 16 kHz |
| 声道 | 单/双声道（**双声道只取首声道**，首声道必须有人声） |
| 内容 | **至少 5 秒连续清晰朗读**，其余仅允许 ≤2 秒停顿；禁背景音乐、环境噪声、其他人声；正常语速说话，不能是唱歌 |
| 敏感词 | 含政治/色情/暴力内容会**直接复刻失败** |

> MiniMax 侧音频要求不同：MP3/M4A/WAV，**≥10 秒、最长 5 分钟**，≤20 MB。

**⚠️ 与本机 F5 产线的差异**：F5 的参考音频规范是 `5–12 秒`，**短于百炼推荐的 10–20 秒**。同一条音频拿去百炼可能偏短（≥5 秒仍合规，只是相似度打折）→ 出片音色要保持系列感，建议单独录/截一条 **12–20 秒、连续无中断**的参考音频。

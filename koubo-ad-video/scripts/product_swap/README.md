# product_swap —— 把真实产品图贴进已有分镜（含锐边 + 动漫描边）

2026-10-05 诺特兰德烟酰胺罐替换素白瓶实战沉淀。0 积分，8 步全流程。

## 用法
改 `swap_product.py` 顶部这几个常量即可复用：

```
OLD          = (443, 261, 555, 573)   # 旧产品实测框（先裁图目视确认！）
CENTER_X     = 500                    # 新产品中心 x
BASE_Y       = 577                    # 新产品底 y（要落在台面上）
TGT          = "target.png"           # 目标分镜图
SRC          = "src.png"              # 真实产品图（PNG/HEIC 转 PNG，带 alpha 最佳）
```

运行：
```
python3 swap_product.py
```
输出两个尺寸的成品（196px / 214px 宽）+ 三联对比图。

## 八步流程（脚本内已按序实现）
1. 裁图目视确认旧产品边界  ← 铁律，不能靠猜
2. 源图 alpha>250 逐行扫轮廓（阈值法会收缩，逐行法最准）
3. 自适应腐蚀清羽化带（顶盖弧顶轻、罐身直边重）
4. 亮度「均值+标准差双对齐」到原柱面（**不能用包络对齐，会白得刺眼**）
5. 柱面光场（按目标实测剖面反光向：横向最亮偏右 0.62、纵向上亮下暗）
6. 环境光染（暖金背景系数 + 侧向受光 + 反弹光）
7. 接地三件套（底部暗脚 → 混台面色 → 接触暗影 + 投影）
8. **动漫白描边**（画在接地之后；先闭运算填凹再膨胀；并入 alpha）
   → 最后一次性 LANCZOS 缩回，直出 PNG

## 关键常量（改这 4 个能调手感）
- `STROKE = int(2.5 * SS)`   描边宽度（先量原图线宽再定）
- `T_LO/T_HI` 或 `core_m/core_s`  亮度匹配目标
- `warm` / `×[1.055,0.985,0.918]`  环境光暖调
- `SS = 3`   超采样倍数（治边缘糊的必需项）

## 血泪提醒
- ❌ **别先存 jpg 再转 png** —— q75 压缩瑕疵烙进像素，边缘永远发糊
- ❌ **USM 只能只锐暗侧**（`np.minimum(diff,0)`），全量会在浅色物体两侧出白边
- ❌ **羽化别超过 0.6px**，1.4px 就把边抹软了
- ❌ **描边别画在接地处理之前**，会被暗脚和锐化吃掉成断续淡线

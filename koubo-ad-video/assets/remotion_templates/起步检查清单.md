# 动效层起步检查清单（v22 定型· 必读）

> 2026-10-08 爱兰纯片v17→v22 血泪实录。**动手前先读完这一页，能省掉 5 轮重渲。**

## 一、开渲前必查（缺一项就会重渲）

| # | 检查项 | 怎么查 | 不做的后果 |
|---|---|---|---|
| 1 | 工程在**依赖完整的原工程**里 | `ls node_modules/@remotion/cli/remotion-cli.js` | `cannot determine executable to run`（极具误导性） |
| 2 | **有 `remotion.config.ts`** | `ls remotion.config.ts` | ★字体永远加载不了，843 帧后卡死 |
| 3 | 帧数算对 | `总秒数 × fps + 1` | 尾巴没渲或被截断 |
| 4 | 入口 id 与文件名同步 | `FxLayerCurrent` ↔ `fx_entry_current.tsx` | 渲染找不到 Composition |

## 二、★ 铁律：绝不能犯的 5 个错

### 1. 绝不在 overlay 层放「铺满全屏的原图」
底片**已经有 Ken Burns**（`zoompan` 推拉）了，再叠一层全屏呼吸＝双重缩放+ 覆盖。
**v21 就是栽在这**：BreathLayer 把分镜原图铺满全屏盖在底片上。

要做动感只有两条路：
- 去**底片 config** 调 `zoompan` 参数（推荐）
- 只加**局部前景元素**（高光、粒子），绝不铺满

### 2. 动效层每帧渲完必须扫 alpha
```bash
/path/python -m pip install pillow   # 一次就够
python -c "
from PIL import Image
im=Image.open('element-100.png')
print(im.mode)   # 必须是 RGBA，若是 RGB 说明 alpha 丢了 → 必出黑闪"
```
★ **为什么必须查 alpha**：亮度检测（灰度均值）在成片上**查不出黑闪**，
因为底片内容本身明暗变化大，会把信号淹没。**只能查 alpha。**

⚠️ 丢了 alpha 的帧会变成**不透明黑图**（左上角像素 `(1,1,1)`）盖住整画面。

### 3. 默认不加镜间转场
黑底镜位（黑板宣言图，灰度仅 22~46）上压暗 → 观感必然是「画面突然黑一下」。
**v21 定型：13 镜硬切**，靠镜位内元素动效保持节奏。

若将来确需加：`dim ≤ 0.15`，且验收「黑底镜位转场帧灰度与相邻帧差 < 8」。

### 4. 同一个信息只能有一种表现方式
`数据可视化 / 重点字 / 产品卡`三者抢同一块注意力。
**有动效就不用重点字弹出**（2026-10-08 灿爹拍板）。
加任何组件前先问：这个信息现在有没有别的表现方式？

### 5. 合规：对比类组件标题禁带功效词
禁用**吸收 / 效果 / 提升 / 见效 / 优于**。用「成分对比」「数值对比」。
（v22 实例：原写「吸收对比」已改为「成分对比」）

## 三、组件清单（v22 定型）

| 组件 | 状态 | 说明 |
|---|---|---|
| `MoteLayer` | ✅ 保留 | 飘尘粒子，alpha 均值仅 11/255，不遮挡主体 |
| `VizOverlay` | ✅ 保留 | 数据可视化（CountUp / RingGauge / CompareBar） |
| `KwOverlay` | ✅ 保留 | 重点字（3~4 个，别多） |
| `ProductCardFx` | ❌ **停用** | ★产品镜禁止用分镜图当卡片弹出（同物重复 + 出场观感乱） |
| `BreathLayer` | ❌ **停用** | ★铺满全屏原图 ⇒ alpha 丢失 ⇒ 黑闪（见铁律 1/2） |
| `TransitionFx` | ❌ **停用** | ★黑底镜位压暗＝黑影闪一下（见铁律 3） |
| `SubtitleLayer` | ❌ **停用** | 底片字幕关不掉，叠自己的会重影 |

## 四、CountUp 显示精度（四层都要改，漏一层报 ReferenceError）

`99.99` 被`Math.round` 舍成 `100`＝「4个9」卖点自打脸。
1. 组件 props 加 `decimals?: number`
2. 显示逻辑 `decimals > 0 ? _raw.toFixed(decimals) : String(Math.round(_raw))`
3. `VizSpec` 类型加 `decimals?: number`
4. 容器透传 `decimals={s.decimals}`

## 五、坐标别猜，先量

同一画面内多组件**必须错开 y**（重叠会糊成一团）。
人物居中构图：左右两侧上方最空，数据可视化放左上/右上，别放正中。
```bash
ffmpeg -ss <t> -i base.mp4 -vf "crop=1000:400:60:480" -frames:v 1 /tmp/area.jpg
```

## 六、音效定位（配置里看不到的 6 类自动音）

渲染器会自动加：开场重击 / 重点字弹簧音 / 镜位甩动 / 转场唿哨 / 分层入场 / 贴纸入场。
**不在 `trigger_sfx` 里**。

- `transition_whoosh` ★**不能不写**——`None` 会套默认 `[5,13]`，必须显式写 `[]`
- 「删音效」通常要**字和音一起删**（重点字自带弹簧音）
- 定位方法：**同底片结构两版互减**（差值 >4dB 处＝音效差异）。
  ★别用「有音效 vs 全静音」互减——BGM 会污染基线，全是噪声。

## 七、ffmpeg 合成（两个必踩的坑）

```bash
ffmpeg -y -i base.mp4 -pattern_type glob -framerate 30 -i "fx/element-*.png" \
  -filter_complex "[0:v][1:v]overlay=eof_action=endall[outv]" \
  -map "[outv]" -map 0:a -c:v h264_videotoolbox -q:v 75 -pix_fmt yuv420p -c:a copy out.mp4
```
- ★必须用 `-pattern_type glob` —— `%04d` 序列会报 `Could find no file or sequence`
- ★帧序列要拷到**工程目录**（`/tmp` 是软链接，ffmpeg 读不到）

## 八、字体（沙箱内必读）

沙箱下 `loadFont` 可能反复不 resolve ⇒ `delayRender` 永久阻塞全片。
**优先级**：① 查 `remotion.config.ts` 在不在 → ② 查字体文件在不在 public/ →
③ **兜底：删掉 `loadFont`+`delayRender`，改系统字体栈**，宁可降级也要出片。

**要点（P2 分镜）**
- 镜数：**图片镜**下限 1.0s／门槛 1.2s（**可快切**，1.0–1.2s 判 ✅）；**视频镜** 1.2s／1.5s（不跟快切）；单句封顶 **4 镜**、>9.5s 拆句；理想单镜 2.2s。
- **🚫 禁止过度合并**——仅在该镜低于绝对下限、或该镜组超配额时才合并；**1.2s 以上的图片镜不得以「偏短」为由合并**。镜数偏多不扣分，**画面单调才扣分**。
- **禁用脸部/手部/局部特写**（中景/全景优先）。
- **科普段（产品被点名之前）禁用一切产品元素**；产品卡落位镜号必须 ≥ 产品点名镜号。
- 素材优先级：**视频 > 图片**；**贴合度 > 省积分**（画面与文案对不上的镜必须新生成）。
- 长句补分镜时：拆 phrase 必须 **`pchars` 守恒**；`keywords`/`product_cards` 是 **1-based**、`swing_shots` 是 **0-based**，插入点之后一律 +1。
- **产品/主体占画面高度大的图，一律直接生成 16:9（1536×864）**（3:2 素材在 `cover + crop_y=0` 下顶部对齐、底部 15.6% 会被裁）。

**要点（P0 灿爹入口 inbox · 2026-09-28 灿爹拍板）**
- **入口位置**：`/Volumes/陈灿会展/广告视频/分镜图库/小绿人/灿爹/`（**只进不存**，正常状态应为空，只剩一个 `README.md` 投料说明）。
- **归档目标**：`/Volumes/陈灿会展/广告视频/分镜图库/小绿人/`（**平铺进主体根目录**，与原生 240+ 素材同层，文件名即检索关键词）。
- **五步流程**：① 递归扫入口（原始文件常**直接丢在根目录**；跳过 `._` 元数据与 `README.md`）→ ② 去水印 + 提清晰度 → ③ 按 `_取名指南.txt` 三段式 `大类_具体画面_景别` 规范重命名 → ④ 平铺归档主体 + 建 `_灿爹归档<日期>/` 留档 → ⑤ **只把「本轮已成功归档的源文件」移入废纸篓**（`/Volumes/<卷>/.Trashes/<uid>/`，可恢复）。
- **命名口径**：第一段取大类（图库既有 `俯卧撑/跑步/举铁/讲课/展示/收尾/生活/餐食/产品/视频`）；第三段必须是**标准景别**（`全身/中景/中近景/近景/特写/全景/大远景/俯拍`）——⚠️ **`半身` 不在规范内，一律改 `中景`**；视频一律 `视频_` 开头，已裁 16:9 可加 `_16x9`。
- **⚠️ 视频必须显式传 `--vrect`**：`auto-multi` 会误检（实测对一段已去水印成片仍在画面中部误检出 2 处「水印」框、修了就毁画面）。**缺 `--vrect` 时 `ingest` 跳过全部视频并保留原文件**（不瞎修也不误删）。
- **落地后必须查重名**：目标已存在时 `ingest` 列冲突并中止，先改名再跑。
- **小云雀水印实测**：图片固定在右下（相对框 `0.834,0.884,0.995,0.981`，跨分辨率一致）；**视频水印多位置漂移＋淡入淡出**＋另有左上固定「AI生成」⇒ **单点 delogo 必漏 → 逐帧对全部位置 inpaint**。
- **去水印四候选择优**：`exemplar`（仅 e²≤1200）/ `inpaint` / `inpaint+邻域纹理迁移` / `inpaint整框`，按「接缝连续性+纹理保真度」打分选优。
- 残留：木纹/白线穿过水印处会留**很轻的柔化痕**（1920×1080 成片里约 230px 宽、实看基本无感）；要绝对无痕须**从源头重新生成不带水印的素材**。

## 五、必做质检（最易漏的坑）

1. **动效夹死检测**：`python3 scripts/qc_motion.py 成片.mp4 config.json`
   残差 <3 = 该镜取景被夹死（画面看着"完全静止"），必须修表达式重渲；正常应 >8。
2. **音量 + 白名单登记**：新音效入库前必须与现有音效同峰值（-9dBFS），否则会出现某个音效突然炸一下；并且**必须同时登记进 `build_ad_video.py` 的 `sfx_files` 白名单与 `DEFAULT_SFX_VOL`**——渲染器只认白名单，光把 wav 丢进 `assets/sfx/` 不会加载（config 的 `sfx_files` 字段能临时注册，但别依赖）。
3. **构图**：抽帧看人物是否出画、有无黑边。
4. **逐镜抽帧质检**：`python3 scripts/qc_frames.py --config config_1.json --video <成片.mp4> --out qc/sheet_1.jpg` —— 每镜中点抽一帧拼联络图，逐张目视「素材是否入片 / 是否撞图 / 画面是否正常」。
5. **重点字落帧核验（必跑）**：`python3 scripts/kwcheck.py --config config_1.json --video <成片.mp4> --out qc/kwsheet_1.jpg` —— `shot_plan` **查不出大字是否压在主体身上**。大字压人 ⇒ 在 config 的 keywords 项加 `"pos":[x,y]` 手钉空白带重渲（实测条3 镜14「维C维E」压左臂，字框内主体占比 0.185 → 手钉后 0.001）。
6. **响度 / 真峰值复检**：`ffmpeg -i 成片.mp4 -af loudnorm=print_format=summary -f null -` 看 **Input True Peak 须 ≤ −0.3 dBTP**（**换过配音段后尤其必查**：实测被 loudnorm 单遍顶到 **+0.4 dBTP 削波**，需 `-c:v copy -af "alimiter=limit=0.85:level=0"` 限幅重封装）；Integrated 目标 **−11.5 LUFS**。

## 六、踩过的坑（别再犯）

- **全片横向拉伸 18.5%**（2026-09-17 修复，潜伏最久）：中间画布写成 3:2（2880x1920）却让 zoompan 输出 1080P（16:9），等于把 3:2 硬拉宽。图库 24/25 张是 3:2 素材，所以每条片的人物都被"拉宽"过，只因没有圆形/人脸参照物一直没被发现。现在画布统一 16:9，3:2 素材改为垂直裁切（默认保头切脚）。
- zoompan 表达式**不支持 `clamp()`**，只能用 `min(max(...))`。
- 带 tilt（倾斜）的镜头要 `scale=3104:1746` 预放大，zoompan 的 zoom 必须 **乘** 1.0778。写成除法 → zoom<1 → 取景框被夹死 → 该镜完全静止。
- fg 层缩放必须用 zoompan（`scale`/`crop` 的宽高只在初始化时求值）；fg 输入单帧不能加 `-loop`。

### 2026-09-29 ★★去水印换代：「模板笔画掩膜」取代「整框填充」（覆盖本文件前面各条去水印表述）

**结论一句话**：水印形状固定 ⇒ **标定 alpha 模板、只填笔画**；**「整框填充」这条路本身是错的**，无论怎么调参。

- **踩的坑**：第 2 批 27 张里 **6+ 张**在平滑渐变/纹理背景上留下**边界清晰可见的色块** ——
  深棕桌面被填成**浅米色**、木地板被**抹糊**、深蓝底出现**矩形补丁**、浅灰底出现**斜边色块**。
- **根因（路线错误，非参数问题）**：旧 `clean_image_wm` 的**全部候选都是整框填充**
  （`flat-fill` 中位色铺满 / `inpaint-rect` 整框 inpaint / `exemplar` 搬源块）。
  `flat-fill` 准入只看 `bg_tex<3.5 && edge_std<11` —— **只测 ROI 外环带是否平滑，
  看不出框内横跨了内容边界** ⇒ 水印框同时压住「桌面 + 背景」时，中位色只能取一个值，
  **必然把一半填错**。「残影守门」只保证「水印抹掉了」，**保证不了「填对了」**。
- **正解三步**：
  ① **标定**：任取一张 5504×3040 原图，在 ROI 上用**上/左两条环带做平面拟合**预测背景 →
     `alpha = clip((P−B)/(255−B), 0, 0.99)`（实测 295×886 上字形锐利，可直接当模板）；
  ② **定位**：相对框 `0.834,0.884,0.995,0.981` **跨分辨率稳定** ⇒ 按 ROI 尺寸缩放模板即可，
     **不再需要多尺度互相关**；
  ③ **掩膜**：`alpha>0.03` → **膨胀 12px** → `inpaint(TELEA, r=6)`。
- **参数档位（实测扫描定档）**：`dilate` 3px 留水印轮廓淡影 / **12px 才干净** / 16px 起发糊；
  `th` 0.03 优于 0.08（低阈值把抗锯齿边缘一并纳入）。
- **验证口径**：27 张残留量降到原图的 **1%~27%**，且**全部低于各区域自身的自然纹理基线**
  ⇒ 剩下那点起伏只是背景纹理本身，不是水印。旧版全部备份于 `_旧版备份/260929_整框填充版/`。

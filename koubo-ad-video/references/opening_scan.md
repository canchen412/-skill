## 一、它是什么

**标准开头（`--skip-banner`）时，镜 1 的静图会被换成一条「RGB 故障 + 扫描重建」的短片**：

```
0.00–0.44   26 级台阶自上而下「数字重建」，没建好的部分去饱和压暗
            同期：RGB 三通道错位 92px / 横向切片错位 170 / 整行撕裂 265
                 扫描线 / 亮度加权噪点 / 故障色块（青·洋红·蓝三色）
0.46        白闪归位 0.95 + 推镜 1.36 → 1.00
1.00–1.24   二次故障（强度 0.62），节奏续住
1.92–2.10   三次弱故障（强度 0.30）
尾部        轻推近 + 暗角淡出 → 末帧就是干净原图，切下一镜不跳
```

**不改变任何时间轴**：镜 1 的起止、口播、字幕、重点字全部照旧，只是这镜的画面变成了一条自带运镜的视频。
**0 积分**：2.3~3.6s 镜约 15~25 秒渲完。

## 二、什么时候生效 / 怎么关

| 条件 | 说明 |
|---|---|
| ✅ 标准开头（`--skip-banner` 且无旧卷播） | 卷播开头不走这个（卷播有自己的 3D 卡列） |
| ✅ 镜 1 是**静图**（`kind: "img"`） | 镜 1 本身是视频镜时跳过（不能对视频做扫描） |
| ❌ 关掉 | config 顶层或 `.kw.json` 侧车写 `"first_frame_fx": false` |

日志会打：

```
══ 4.5 镜1 扫描重建入场（261017_04_货架挑牌子.jpg → 3.72s）
  镜1 换为扫描重建短片（k=1.00，音效 5 点对点）
```

失败时**回退原图继续出片**，不阻断（`⚠️ 扫描重建失败，镜1 回退原图`）。

## 三、时长怎么定

镜 1 时长 = 下一镜首字起点 − 本镜首字起点（句间静音算本镜内，与渲染器一致），
脚本按 `min(3.60, max(1.20, 镜长 + 0.30))` 生成：

- **多给 0.30s 余量**：渲染器按实际镜长 `trim`，宁长勿短——短了会把最后一帧冻住
- **动效时间轴按 `k = min(1.0, dur × 0.78 / 2.30)` 等比压缩**（`TAIL_KEEP=0.78`）：
  - `dur=2.48` → k=0.84，动效 1.76s 跑完，**留 0.72s 干净画面**再交棒
  - `dur=1.50` → k=0.51，0.24s 重建完、0.51s 二次故障、0.98s 三次故障，1.07s 收干净
  - 台阶数随 k 减少（`max(8, 26*k)`），短镜不会因为台阶太多而一片糊
- **★为什么不是 k=dur/2.3**：第一版就是那么算的，结果 2.48s 的镜只留 **0.08s** 干净画面，
  切下一镜时观众还停在故障帧上。**必须留出干净尾巴**。
- **★尾巴不是 0.35s 就够**：0.86 试过一轮，帧差峰值仍到 150（回拉太急，观感像「突然拉远」）。
  0.78 之后回拉的帧差峰值降到 36，变成一次缓慢呼吸。
- **干净尾巴里推镜缓回 1.0**（不是继续推近）：末帧＝原图全幅，接下一镜不跳
- **k 由脚本写出（`--emit-k`），流水线读文件**——两边各算一遍会漂（脚本含 TAIL_KEEP），
  音效就会比画面早或晚。

## 四、音效（按硬节拍对点，不是靠关键词）

`pipeline_run.py` 把 4 件「爆款叙事音效」按绝对时刻注册进 `sfx_files` + `sfx_at`：

| 时刻（×k） | 音效 | 作用 |
|---|---|---|
| 0.02 | `09_秒针倒计时` | 数字重建的暗示，垫底 |
| 0.46 | `01_开场闪光转场` | 白闪归位 |
| 0.47 | `10_震惊闷响` | 归位那一击的重量（与闪光**同时叠**，是设计） |
| 1.00 | `07_金属敲击_短促` | 二次故障 |
| 1.92 | `07_金属敲击_短促` | 三次故障 |

音量：`k≥0.8` → tick 0.52 / flash 1.06 / thud 1.12 / metal 0.60；`k<0.8` 略收。

**★踩过的坑**：第一版 flash 0.74 / thud 0.82，实测峰值只比邻域高 2dB，
**耳朵听不出「归位那一击」**——因为镜 1 的口播从 0.2s 就开始了，人声把音效压住了。
归位双响必须 1.0+ 才压得住人声。

## 五、渲染器的两个配套改动（都在这轮加的）

### 1. `no_zoom`（imgvid 镜不二次推近）

`build_ad_video.py` 的 imgvid 分支原本固定叠 `zoompan 1.06→1.14`。我们的扫描片**自带运镜**，
再放大一次会：① 多裁 6~14% 画面（末帧就不是原图全幅了，接下一镜会跳）；
② 多一道重采样把扫描噪点糊掉。

所以 phrase 里写 `{"kind": "imgvid", "no_zoom": true}` → 走 `scale=1920:1080 + trim`，原样入片。

### 2. `sfx_at`（按绝对时刻指定音效）

```json
"sfx_files": {"scan_flash": "/abs/path/01_开场闪光转场.wav"},
"sfx_at": [[0.46, "scan_flash"], [0.47, "scan_thud"]],
"sfx_volume": {"scan_flash": 1.06, "scan_thud": 1.12}
```

- `sfx_files` 的值可以写**绝对路径**（`os.path.join` 遇绝对路径直接返回它）
- `sfx_at` 独立成组：**不参与正片「5 秒响亮互斥」**，组内**不做最小间隔**（白闪+闷响本来就同时）
- 之前只有 `trigger_sfx`（按关键词触发），对不上硬节拍，这是补的

## 六、为什么是这一招（选型依据）

同一张训练图跑三套动效的实测结论（2026-10-21）：

| 手法 | 强项 | 弱项 |
|---|---|---|
| A 条带汇聚 | 一块块读画面，拼装感强 | 起手 0.4s 看不到全貌；**暗帧上完全失效**（条带本身是黑的） |
| **B 扫描重建** | **30 帧内完成建立，最炸；有中间调就成立** | 挑品类：数码/潮牌/健身装备吃得住，讲成分养生会像盗版软件广告 |
| C 光染色揭示 | 有叙事（灰暗被点亮），电影感 | 必须有暗部，白底图废掉一半 |

镜 1 是钩子镜（要 1 秒抓人），B 最快最炸；**但品类不可控，所以默认款换成了 A（条带汇聚）**——
A 不会翻车，B 只在「故障感本身值钱」的品类（数码/潮牌/装备）才切。
⚠️ 表里「A 在暗帧上失效」是当时的误判：条带装的是图自身的像素不是黑块，A 靠几何位移，
暗帧照样读得出飞入。真正怕暗的是 B（亮度差没了就没有「重建中」的读感）。

## 七、单独调用（调试 / 出对比样片）

```bash
PY=/Users/mac/.workbuddy/binaries/python/envs/default/bin/python
$PY ~/.workbuddy/skills/koubo-ad-video/scripts/opening_scan.py \
    --src 图.png --out /tmp/scan.mp4 --dur 2.60 \
    [--strength 1.15] [--fit contain] [--fps 30] [--seed 77]
```

- `--fit cover`（默认）满屏裁切，与渲染器一致；`--fit contain` 竖图/异形图等比缩放 + 模糊铺底
- `--strength` 1.0 是定稿值；配暗调素材可到 1.15，配白底图降到 0.85（否则故障太糊）
- 输出**必须无音轨**：渲染器会把带音轨的镜判成「自带混音」并屏蔽全局 vo，
  结果镜 1 口播整段消失（2026-10-09 卷播踩过，见 SKILL #195）

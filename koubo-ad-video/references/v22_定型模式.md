# ★ 成片默认定式 = 肌酸 v22 模式（2026-10-08 灿爹拍板）

> 原话：「这个就对了」。**之后所有带货成片默认走本模式**，除非灿爹明确要求别的风格。
> 来源：爱兰纯肌酸 261008 · v22 定型（成片 `成片/爱兰纯肌酸_v22_根治黑闪_1080P.mp4`，32.27s/1080P/1000帧全出/音轨在位）。
> ⚠️ 本文件与《流程速查表.md §二 交付标准》冲突时，**以本文件为准**。

## 一、结构：底片 + Remotion 动效附加层（两截拼）

```
① 底片：config 里 keywords=[] product_cards=[] → 干净底片（字幕保留）
② fx 层：fx_entry_<x>.tsx 三层叠加 → npx remotion render ... --sequence --image-format=png（输出目录不带扩展名）
③ 合成：ffmpeg overlay=eof_action=endall（fx 输入用 -framerate 30 -i fx_frames/element-%04d.png）
```

### ★ 卷播接缝吃字幕——合成后必须二次烧录（2026-10-08 VORSE姜黄素灿爹抓出）

卷播（0→3.70s）整体覆盖底片开头 ⇒ 底片被盖区间的前两句字幕**一起被吃掉**，
而正片从接缝起字幕正常 ⇒ 观感就是「前两句没有字幕」。
**修法（合成最后一步）：** 从 `s1/subs.ass` 截取 start < 卷播总长 的事件（末条 end 截到 3.70）
生成 `banner_subs.ass`（样式头照抄），对**成片全片**跑
`-vf subtitles=banner_subs.ass -c:v h264_videotoolbox -q:v 75 -c:a copy` 重编码。
字幕只在 0→3.70 有事件，其余段不受影响；接缝处同句字幕与正片原字幕自然衔接。
⇒ 此步必须写进 assemble 脚本，验收时抽 t=1s/3s 帧看卷播段字幕在不在。

### ★ 封面段：成片最前面加 **1 帧** 旧版封面（2026-10-08 VORSE姜黄素灿爹两次拍板）

> 第一次做成 0.5s 静帧+BGM 头，灿爹否掉：原话「开头封面只要一帧就行，几乎对视频不影响，
> 你这个 bgm 都响了两次了」。⇒ **封面段 = 1 帧静图 + 零音频**，不铺任何声音。
**做法：** 从旧批次成片抽无损首帧（`-frames:v 1 -q:v 1`）→
`-loop 1 -t 0.034 -r 30` 做 1 帧段，`filter_complex concat` 到成片最前，
**音频直接 `-map 1:a -c:a copy` 原样 copy**（BGM/配音零改动零重复）。
总时长 +0.033s，仅首帧是封面（抖音封面=首帧用途达成），观感对正片无影响。

方法论与脚本见 `remotion_动效层.md §0.2`（kw_times.py / pick_kw_pos.py / qc_v14b.py）。

### ★ 渲染环境三坑（2026-10-08 VORSE姜黄素实测，fx 层**禁走视频编码**）

1. **fx 禁止渲成 vp9/vp8 webm**：Remotion 自带合成器对 libvpx 的 alpha 编码**静默降级**
   （yuva420p → yuv420p 单流，alpha 全丢、画面全黑 opaque）。抽帧看是黑的、ffprobe 只有 1 条流。
   **只走 PNG 序列**（截屏端 omitBackground 自动开、alpha 保真），overlay 直接吃 `element-%04d.png`。
2. **node 渲染命令必须 `NODE_OPTIONS= `（清空）前缀**：WorkBuddy 注入的
   `node-language-shim.cjs` 垫片会把 Remotion bundle 的 mkdir 报成假 EEXIST
   （`createBrokerPolicyError`），CLI/SDK 全挂；清空 NODE_OPTIONS 即通。
   沙箱若再拦（EPERM unlink webpack cache），配 remotion.config.ts
   `Config.overrideWebpackConfig((c) => ({...c, cache: false}))` 并清 `node_modules/.cache/webpack`。
3. **本机 headless Chrome 的 loadFont/FontFace 全部悬死**（staticFile 网络 fetch 与 data URI
   都会 delayRender 超时）：商业字体（新青年体等）**装进系统** `~/Library/Fonts/`，
   Chrome 原生识别，fx 入口及其 import 链**不得出现任何 loadFont/delayRender**
   （MarqueeClickD/DataViz/SubtitleLayer/Marquee3D 都有模块级 loadFont，fx 专用入口别 import 它们）。
   ⚠️ grep 排查要用 `grep -rEn "loadFont\(|delayRender\("`（-E），BRE 的 `\|` 是假阴性。

## 二、fx 层保留的三种组件（也是上限参考）

| 组件 | 用途 | v22 实例 |
|---|---|---|
| `MoteLayer` | 飘尘粒子（alpha 均值 ~11/255，不遮主体） | 镜 3/6/9/12 |
| `VizOverlay` | 数据可视化（每个数字只做一种表现，铁律8.8） | 99.99% / ¥0.22每天 / 50万单 |
| `KwOverlay` | 重点字（比 ffmpeg 线性滑动有重量感） | 超不超标 / 随货 |

⚠️ **VizOverlay 传参两坑（2026-10-08 VORSE 实测）**：
- `ring` 的 `value` 传 **0~1 小数**（组件内部 ×100 显示+滚动），传 98 会滚出「8913%」灾难帧；
- `bar` 的标题用 `title:` 传**中性词**（如「优惠对比」），组件默认硬编码「吸收对比」踩 §六 红线。

## 三、★ 停用的四个组件（默认不开，别再犯）

| 组件 | 停用原因 |
|---|---|
| `TransitionFx` | 黑底镜位压暗 ⇒ 画面突然黑一下 |
| `BreathLayer` | 铺满全屏原图 PNG 丢 alpha ⇒ 不透明黑图盖屏 ⇒ **分镜内部黑闪** |
| `ProductCardFx` | 产品镜用分镜图当卡 ⇒ 同物重复 + 压头 |
| `SubtitleLayer` | 底片字幕关不掉（sub_max_lines 强制下限1），叠了重影 |

## 四、转场与音效

- `transition_whoosh: []` ★**必须显式写空数组**（写 None/缺省会被 build_ad_video.py 套默认 `[5,13]`）；`opening_burst: false`。
- **叙事音效 trigger_sfx（3 个封顶，按叙事功能选位）**：
  - 抛问设悬念 → `narr_query`（03_短促疑问音，anchor=shot 镜首）
  - 揭示盲区/震惊 → `narr_shock`（10_震惊闷响，anchor=kw）
  - 销量/价格重锤 → `narr_thump`（08_沉重心跳_低频重击，anchor=kw）
- 音效库已入技能资产：`assets/sfx_爆款叙事音效/`（14 款 + sfx_mapping.json + README 对照表）。
- **克制原则**：3 个封顶；旧款的批批/含金量处/最后分镜处音效一律不加。重点字音效（kw_* 19款池）与叙事音效**不同时叠**。

## 五、ffmpeg 底片定参（v20 config 实值）

vo_gain 1.46 / bgm_volume 0.24 / sidechain 闪避 / loudnorm -11.5 LUFS / TP≤-0.3dBTP / sub_size 78。

## 六、合规红线（v22 新增）

对比类组件标题**禁用**：吸收 / 效果 / 提升 / 见效 / 优于（功效暗示）。用「成分对比」这类中性表述。

## 七、验收必查：alpha 黑闪扫描

亮度检测**查不出黑闪**（底片明暗变化淹没信号）。必须扫 fx 层 PNG 的 **alpha 通道**：
- `im.mode` 须为 `RGBA`；
- alpha 均值不得有 >25 的跃升（v22 修后上限 11.37）；
- 脚本参考 `qc_v14b.py`。

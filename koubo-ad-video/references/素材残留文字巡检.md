# 素材残留文字 / 水印巡检（2026-10-28 烟酰胺诺特 v1 建立）

> 起因：一条片子的 43 张垫图里，**6 张底部烧着字**，肉眼翻联览图全漏了，成片里直接露。手机全屏看不出来，投流放大就穿帮。

---

## 一、为什么必须全池 OCR

生成器出的图经常带三类东西，都在**底部 12% 区域内**：

| 类型 | 实例（本轮实测） |
|---|---|
| 生成器水印 | `AI生成` + `WORKBUDD>.`（右下角，浅灰半透明） |
| 分镜编号条 | `SHOT. 351`、`SHOSER HEATv`、`TURNING POINT` |
| 中文乱码字幕 | 「现在多司鉴物的三价差款分啦」、「hmryeeurpti」 |

**肉眼抽查必漏的三条原因**：
1. 联览图每格只有 380px 宽，底部 20px 的字缩成 2-3 像素的灰糊；
2. 暗棚镜头的字和背景明度接近，缩图后彻底融掉；
3. 同一个池子里 90% 的图是干净的，看前几张没字就会放松警惕。

---

## 二、扫描：PyObjC Vision（本机自带，零依赖零积分）

macOS 自带 Vision framework，中文识别率比 tesseract 高一个档，**43 张约 6 秒**。

```python
import os, json
import Vision, Quartz
from Foundation import NSURL

def ocr(path):
    url = NSURL.fileURLWithPath_(path)
    src = Quartz.CGImageSourceCreateWithURL(url, None)
    img = Quartz.CGImageSourceCreateImageAtIndex(src, 0, None)
    req = Vision.VNRecognizeTextRequest.alloc().init()
    req.setRecognitionLevel_(0)                            # 0=accurate
    req.setRecognitionLanguages_(["zh-Hans", "en-US"])
    req.setUsesLanguageCorrection_(False)                  # ★必须关，否则乱码被"纠正"成正常词
    h = Vision.VNImageRequestHandler.alloc().initWithCGImage_options_(img, None)
    h.performRequests_error_([req], None)
    out = []
    for r in (req.results() or []):
        c = r.topCandidates_(1)[0]; bb = r.boundingBox()
        out.append({"t": c.string(), "c": round(float(c.confidence()), 2),
                    "x": round(float(bb.origin.x), 3),
                    "y": round(1 - float(bb.origin.y) - float(bb.size.height), 3),  # 转成左上原点
                    "w": round(float(bb.size.width), 3),
                    "h": round(float(bb.size.height), 3)})
    return out
```

跑完全池写一份 `json`，**按 `y` 排序看**：`y ≥ 0.88` 的就是底部水印带，`y < 0.88` 的才是画面内容（比如瓶身标签）。

> `setUsesLanguageCorrection_(False)` 是关键。开着它，`SHOSER HEATv` 会被"纠正"成像是正常英文，反而不易发现是垃圾。

## 三、处理 A：裁切（简单，有构图代价）

保留上部 85.5%，居中收宽补回 16:9，重采 1920×1080：

```python
KEEP = 0.855
h2 = int(h * KEEP); w2 = int(round(h2 * 16 / 9)); x0 = (w - w2) // 2
im2 = im.crop((x0, 0, x0 + w2, h2)).resize((1920, 1080), Image.LANCZOS)
im2 = im2.filter(ImageFilter.UnsharpMask(radius=1.2, percent=52, threshold=2))
```

- 优点：一次清干净，批量无脑跑。
- 缺点：**底部损失 14.5%**。人物脚部/产品底边可能被切，逐张目视复核构图（本轮 22 张验过，人物头部都完整）。
- 适用：底部本来就是地面/桌面的镜头。

## 四、处理 B：局部镜像修补（★推荐，构图零损失）

水印只占右下角一小块时，用**同高度的左侧地板镜像**盖掉，暗部完全看不出。

```python
from PIL import Image, ImageFilter, ImageOps
import numpy as np

x0, y0 = int(W*0.885), int(H*0.895)          # 水印区起点（略大于水印本身）
bw, bh = W - x0, H - y0
# 从同高度的左边取一块同宽背景，水平镜像 → 纹理方向自然
src = im.crop((x0 - bw*2, y0 - int(bh*0.35),
               x0 - int(bw*0.4), y0 - int(bh*0.35) + bh)).resize((bw, bh), Image.LANCZOS)
src = ImageOps.mirror(src).filter(ImageFilter.GaussianBlur(1.4))
# 羽化遮罩：左边缘 + 上边缘渐变，避免出现硬方块边界
m = np.full((bh, bw), 255.0, dtype=np.float32)
fw, fh = max(6, bw//6), max(4, bh//5)
for i in range(fw): m[:, i] = np.minimum(m[:, i], 255.0 * i / fw)
for j in range(fh): m[j, :] = np.minimum(m[j, :], 255.0 * j / fh)
mask = Image.fromarray(m.astype(np.uint8)).filter(ImageFilter.GaussianBlur(2))
im.paste(src, (x0, y0), mask)
```

**三条要点**：
1. **水平镜像**——直接贴会把纹理方向贴出接缝，镜像后就顺了；
2. **羽化左/上两条边**（水印区的右/下贴画面边缘，不用羽化），否则出现硬方块；
3. **先 `GaussianBlur(1.4)` 再贴**，抹掉取块处本身的细节差异。

修完必须**放大到 900px 宽目视复检**，确认没有拼接痕、没有残留字。

---

## 五、验收（缺一不可）

1. 修补后的图**再跑一遍 OCR**，确认零命中；
2. **放大右下角**（900px 宽）目视看拼接痕；
3. 成片里按该镜时刻抽帧，再确认一遍（调色/压缩可能让弱水印重新浮现）。

## 六、顺手要查的另一件事：瓶身标签

同一批 OCR 结果里，`y < 0.88` 且落在瓶身区域的文字，**很可能是 AI 画的假标签**。本轮实测整池持瓶图标签全是乱的：

| OCR 读出 | 真实包装 |
|---|---|
| 诺特兰倌 / 诺特兰估 | 诺特兰德 |
| 维生素E·维生素E（重复字） | 维生素C + 烟酰胺 + 维生素E + 葡萄籽提取物片 |
| +40mm | 260 片 |
| 净含量2600片 | 260 片 |

**手机上看不清、放大就露**。这属于素材本身缺陷，**裁切和水印修补都治不了**，只能重生成持瓶图（约 9 分钟一张）。发现后**必须主动告诉灿爹**，让他决定要不要返工，不能自己瞒着交片。

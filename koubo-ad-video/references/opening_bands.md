## 一、它是什么

**标准开头（`--skip-banner`）时，镜 1 的静图会被切成 9 条横带，错时飞入拼合成整图**：

```
0.02–0.63   9 条横带飞入：奇偶分左右两侧，每条 0.026s 阶梯、单条 0.40s 到位
            条内内容反向视差 0.36（越靠边的条带错得越多）→ 假 3D 的「拼装感」
            飞行中条带带 5px 白边，收到位即消失
0.63        合缝光：横线从画面中心向两侧张开（细、快、淡，0.30 → 0）
0.68–1.42   速度线 38 条横向掠过 + 准星框从 1.26x 收紧贴合画面边缘
            推镜 1.00 → 1.080 → 1.185
1.30–1.42   ★冲击：白闪 0.52 + 推镜加速（音重重锤压这里）
1.42–2.00   回落 z → 1.0、暗角淡出 → 末帧＝干净原图，切下一镜不跳
```

**不改变任何时间轴**：镜 1 的起止、口播、字幕、重点字全部照旧，只是这镜的画面变成了一条自带运镜的视频。
**0 积分**：2.0~3.6s 镜约 25~35 秒渲完（比 B 慢一点，条带飞入段有 4x 运动模糊采样）。

### 为什么默认是 A 而不是 B（选型结论）

| | A 条带汇聚 | B 扫描重建 |
|---|---|---|
| 品类适配 | **中性**：机械拼装感，健身/数码/食品/成分都能用 | 挑品类：讲成分养生像盗版软件广告 |
| 暗帧表现 | 靠几何位移，画面再黑也读得出「一条条飞进来」 | 靠「重建区 vs 未重建区」的亮度差，暗帧一片糊 |
| 收尾 | zoom 在基准末点精确回 1.0，天然不跳 | 需要额外回拉（踩过两轮） |
| 抓人强度 | 前 0.4s 看不到全貌，第 0.63s 拼合才「炸」 | 0.44s 建完，0.46 白闪，最快 |

镜 1 是钩子镜，B 确实更快更炸；但**默认片型不可控**，A 不会翻车。想要 B 的炸，就单独切款。

| 条件 | 说明 |

## 三、时长怎么定

镜 1 时长 = 下一镜首字起点 − 本镜首字起点（句间静音算本镜内，与渲染器一致），
脚本按 `min(3.60, max(1.20, 镜长 + 0.30))` 生成：

- **多给 0.30s 余量**：渲染器按实际镜长 `trim`，宁长勿短——短了会把最后一帧冻住
- **动效按 `k = min(1.0, dur × 0.86 / 2.00)` 等比压缩**（`TAIL_KEEP=0.86`，基准 2.00s）：
  - `dur≥2.33` → k=1.00，动效 2.00s 跑完，尾巴是**静帧 + 极慢推近 0.028**（幅度小到看不出来，但画面活着）
  - `dur=2.00` → k=0.86，动效 1.72s 跑完，留 0.28s 干净画面
  - `dur=1.20`（下限）→ k=0.52，条带 0.21s 一条飞入 1.03s 全部到位——很赶，但动效完整
- **★为什么留 0.86 而不是压到底**：A 的收尾（1.42→2.00）本身就是从 1.185 缓回 1.0 的呼吸，压太紧就变成
  「突然拉远」。B 那边踩过：0.86 时帧差峰值 150，降到 0.78 才降到 36。A 的回拉更缓（0.58s），0.86 够。
- **k 由脚本写出（`--emit-k`），流水线读文件**——两边各算一遍会漂（脚本含 TAIL_KEEP），
  音效就会比画面早或晚。

## 四、音效（按叙事节点对点，不是靠关键词）

`pipeline_run.py` 按绝对时刻注册进 `sfx_files` + `sfx_at`（时刻 × k）：

| 时刻（×k） | 音效 | 作用 |
|---|---|---|
| 0.02 | `06_疾速机器滑音`（裁到 0.62s） | 条带在轨上滑进来 |
| 0.11 | `13_力量迸发渐强`（1.18s，自然长度） | 准星收紧的紧张感，正好在冲击时爆 |
| 0.628 | `07_金属敲击_短促` | **合缝**那一记（拼图对上的反馈） |
| 1.296 | `07_金属敲击_短促` | 冲击的硬度 |
| 1.298 | `01_开场闪光转场` | 冲击的高频（与金属**同时叠**，是设计） |
| 1.318 | `08_沉重心跳_低频重击`（裁到 0.55s） | 冲击的重量 |

音量：`k≥0.8` → slide 0.46 / riser 0.44 / metal 0.64 / flash 0.46 / thud 0.96；`k<0.8` 各收一档。

**★两件要预先裁**：`06` 原长 2.18s（会念到合缝之后）、`08` 原长 1.48s（尾巴拖）。
`sfx_at` 只支持定点，不支持逐件裁切/淡出，所以第 4.5 步用 ffmpeg 先裁到 `{S}/render/sfx_band_*.wav`
再注册成 `band_slide` / `band_thud` 两个新音色名。

**★音量按「有人声」调，不是按 demo 调**：demo 是无人声单独混的，直接搬进正片会被口播压住
（B 踩过：0.74/0.82 峰值只比邻域高 2dB，耳朵听不出归位那一击）。所以整套比 demo 抬了一档。

## 五、渲染器的两个配套改动（2026-10-21 这轮加的，B/A 共用）

### 1. `no_zoom`（imgvid 镜不二次推近）

`build_ad_video.py` 的 imgvid 分支原本固定叠 `zoompan 1.06→1.14`。入场短片**自带运镜**，
再放大一次会：① 多裁 6~14% 画面（末帧就不是原图全幅，接下一镜会跳）；② 多一道重采样把细节糊掉。

phrase 里写 `{"kind": "imgvid", "no_zoom": true}` → 走 `scale=1920:1080 + trim`，原样入片。

### 2. `sfx_at`（按绝对时刻指定音效）

```json
"sfx_files": {"band_slide": "/abs/slide.wav", "band_thud": "/abs/thud.wav"},
"sfx_at": [[0.02, "band_slide"], [1.318, "band_thud"]],
"sfx_volume": {"band_slide": 0.46, "band_thud": 0.96}
```

- `sfx_files` 的值可以写**绝对路径**（`os.path.join` 遇绝对路径直接返回它）
- `sfx_at` 独立成组：**不参与正片「5 秒响亮互斥」**，组内**不做最小间隔**（闪+重锤本来就同时）
- 之前只有 `trigger_sfx`（按关键词触发），对不上硬节拍，这是补的

## 六、单独调用（调试 / 出对比样片）

```bash
PY=/Users/mac/.workbuddy/binaries/python/envs/default/bin/python
$PY ~/.workbuddy/skills/koubo-ad-video/scripts/opening_bands.py \
    --src 图.png --out /tmp/bands.mp4 --dur 2.60 \
    [--strength 0.8] [--fit contain] [--fps 30] [--seed 20261021]
```

- `--fit cover`（默认）满屏裁切，与渲染器一致；`--fit contain` 竖图/异形图等比缩放 + 模糊铺底
- `--strength` 收放的是**白边 / 速度线 / 准星框 / 白闪**四层（几何位移不变）：1.0 定稿；
  配干净白底图可到 0.85（否则速度线太闹），配暗调素材可到 1.1
- 输出**必须无音轨**：渲染器会把带音轨的镜判成「自带混音」并屏蔽全局 vo，
  结果镜 1 口播整段消失（2026-10-09 卷播踩过，见 SKILL #195）

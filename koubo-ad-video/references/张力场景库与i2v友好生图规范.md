# 张力场景库 · i2v 友好生图规范

> 起因：灿爹 2026-10-07 ——「生成的图很死，需要脑洞场景（赛博朋克/冰川/火焰）、光影加粒子，而且图片要非常适合生成视频」
> 前提：后期调色增强方案已被审美否决，**只走生图源头**

---

## 〇、一个决定成败的原理

**i2v（图生视频）只能让画面里"本来就能动的东西"动起来。**

模型在 5 秒内只能做**小幅、连续、可预测**的运动。如果图里没有可动元素，它就只能整体漂移或让人物"橡皮化"——这就是"图很死、生不出好视频"的根本原因。

| 图里有 | i2v 结果 |
|---|---|
| 火焰 / 烟雾 / 蒸汽 / 粒子 / 飘带 / 头发 / 衣料 / 水面 / 雨雪 | ✅ 天然有运动抓手，5 秒能出好片段 |
| 白底人物 + 空旷背景 + 无任何可动物 | ❌ 画面整体漂移，人物脸和手会拧巴 |
| 满屏静态建筑/货架/密集人群 | ❌ 纹理被"融化"，货架会变行 |
| 极高频细节（金属网、树叶、密集人群） | ❌ 细节抖动崩坏 |

**⇒ 生图时必须显式写进「可动元素」。这是本规范的第一原则。**

---

## 一、prompt 四要素组装公式

```
[主体与动作] + [张力场景] + [硬光影] + [可动粒子] + [风格统一]
```

**通用可动元素池（写进 prompt，任意组合 2–3 种）**：
> 飘散的火星与余烬 / 上升的蒸汽与热浪 / 缓慢飘落的灰尘 / 空中悬浮的尘埃颗粒 / 流动的雾气 / 上升的气泡 / 飘落的雪花与冰晶 / 发光的数据流与粒子丝 / 缓慢下落的玻璃碎片 / 被风掀起的衣角与头发 / 飞溅的水花

**硬光影词库（每张必带 2–3 个）**：
> 强侧光且阴影边缘清晰 / 顶部硬光打出轮廓 / 体积光束穿过空气 / 地面湿反射 / 边缘轮廓光勾主体 / 冷色环境光配暖色主光 / 逆光剪影配发光轮廓 / 镜头光晕 / 浅景深虚化背景

## 二、张力场景库（10 类 · 按情绪选）

### 1. 赛博朋克霓虹 —— 未来感 / 科技 / 潮
- **场景**：雨夜霓虹街道、楼顶天线阵、全息广告牌、地下通道
- **光影**：洋红+青蓝双色边缘光、湿地镜面反射、霓虹光斑洒在人物身上
- **可动元素**：雨丝、地面水洼涟漪、蒸汽从井盖升起、霓虹灯管闪烁、载具尾灯拖影
- **i2v 友好度**：★★★★★（雨/蒸汽/闪烁都是天然运动）
- **配什么文案**：科技感、成分表、数据对比、"我查了成分"类

### 2. 冰川极境 —— 冷 / 纯净 / 力量
- **场景**：冰裂缝深处、蓝冰洞、暴风雪高原、冰面反射天空
- **光影**：透光的蓝冰（内部发亮）、冷白硬光、极光带
- **可动元素**：横向飘雪、悬浮冰晶碎屑、寒雾流动、呼出的白气
- **i2v 友好度**：★★★★★（雪/雾/气都极好动）
- **配什么文案**：干净、纯净、成分天然、控糖控油类

### 3. 火焰炼狱 —— 爆发 / 能量 / 硬核
- **场景**：燃烧的训练场、火山口、熔岩边缘、灰烬弥漫的废墟
- **光影**：**底部跳动的火光从下往上打光**（最强张力的打光法）、浓烟遮天、橙色高光
- **可动元素**：跳动火焰、上升火星、飘散灰烬、热浪扭曲空气
- **i2v 友好度**：★★★★★（火焰+灰烬是 i2v 最擅长）
- **配什么文案**：燃脂、爆发、训练强度、汗流浃背类

### 4. 深海水下 —— 神秘 / 流动 / 高级
- **场景**：水下手持产品、水面透下的光柱、深海裂谷
- **光影**：**水面透下的光柱（焦散光斑打在人物身上）**、幽蓝调
- **可动元素**：上升气泡、漂浮微粒、水流飘动、发丝与衣料飘摆
- **i2v 友好度**：★★★★★（气泡+飘摆极好动）
- **配什么文案**：深度、纯净、海洋成分、矿物质类

### 5. 雷暴风暴 —— 冲击 / 爆发
- **场景**：天台雷暴、暴雨街头、闪电劈下的瞬间
- **光影**：闪电瞬间强曝光（高对比）、湿地面反射
- **可动元素**：暴雨、飞溅水花、积水涟漪、衣料被风压紧
- **i2v 友好度**：★★★☆☆（闪电 i2v 易闪成噪点，靠雨和衣料动）
- **配什么文案**：狠、猛、一下击中、痛点类

### 6. 黑金聚光舞台 —— 高端 / 产品英雄镜
- **场景**：暗场无缝背景、单一聚光台、镜面地台
- **光影**：顶部硬光 + 强轮廓光勾边 + 地台镜面反射
- **可动元素**：金色尘埃缓慢飘落、聚光里浮尘、光束呼吸
- **i2v 友好度**：★★★★☆（尘埃+光束够动）
- **配什么文案**：产品点名、成分卡展示、囤货、性价比

### 7. 超现实尺度 —— 脑洞 / 冲击
- **场景**：产品被放大成建筑、人物缩小站在巨物上、无数个自己排成矩阵
- **光影**：不合理的冷暖对撞、超现实光源
- **可动元素**：漂浮几何碎片、光粒环绕、无尽复制体同步动作
- **i2v 友好度**：★★★☆☆（碎片好动，巨物易变形——**巨物要当背景，不要让主体变形**）
- **配什么文案**：含量高、一瓶顶多瓶、夸张对比

### 8. 镜面无限 —— 对称 / 破碎 / 转折
- **场景**：镜面迷宫、碎裂镜面、无限反射长廊
- **光影**：反射的彩色光斑、多重高光
- **可动元素**：玻璃碎片缓慢下落、反射体的同步动作
- **i2v 友好度**：★★★★☆（碎片下落极好动）
- **配什么文案**：变帅/转变/开篇钩子（**本库 SK06 已是这个路子**）

### 9. 实验室成分 —— 科学 / 成分感
- **场景**：发光实验台、玻璃器皿、蓝色数据流环绕
- **光影**：冷白实验室光 + 液体内部发光
- **可动元素**：上升气泡、数据流、粉末飘散、液体旋转
- **i2v 友好度**：★★★★★（气泡+数据流+液体都好动）
- **配什么文案**：含量、成分、配方、检测

### 10. 工业废墟 —— 硬核 /  gritty
- **场景**：废弃工厂、锈蚀金属、混凝土结构、破碎天窗
- **光影**：**单侧硬光从破损天窗穿入形成光束**、灰尘在光里浮动
- **可动元素**：灰尘、纸屑、冷烟、火星
- **i2v 友好度**：★★★★☆（灰尘光束极好动）
- **配什么文案**：坚持、硬练、不服、长期主义

## 五、验收：数据只作辅助，两条硬指标必须目视

⚠️ **2026-10-07 实测修正**：先前定的「亮部≥5%、白位≥210、跨度≥200」是错的 —— 它只适用于**亮调场景**（赛博/冰川）。
实测两张样张：火焰炼狱亮部仅 **1.23%**、白位 148，但视觉冲击力极强（因为它靠**局部火光**+暗部器械剪影制造纵深）。

**所以真正的验收标准是这两条（只能目视，数据是辅助）：**

| # | 硬指标 | 怎么看 |
|---|---|---|
| 1 | **有明确的主光方向** | 画面能一眼指出"光从哪来"（底部火光/侧光/顶光/霓虹），不是均匀照明 |
| 2 | **有 ≥2 类可动元素** | 火星/蒸汽/雨/雪/烟/粒子/发丝/衣料/水花/光束里的灰 |

**辅助数据（只看趋势，不设硬阈值）**：
- 直方跨度 ≥150 说明层次没被压死
- 饱和 60–120 区间较自然；>150 会显得"廉价艳"（AI 味重）
- **暗调场景看局部高光**（火光/霓虹/屏幕），别看全局亮部

## 五之二、平台水印处理

Miora 生图会在**右下角打「AI生成 WORKBUDDY」**，相对框约 `x 0.86–1.00, y 0.898–1.00`（图右下角贴边）。

**去水印优先级**：
1. **镜像填充（实测最实用，0 成本）**：取左侧等宽同高区域水平镜像铺到右缘 + 边缘高斯羽化。
   适用前提：右下角是**纵向延伸的纹理**（湿地涟漪、地面、墙面）。高频复杂纹理会有拼接痕，但在动态成片里看不出来。
2. **`wm_remove.py`（技能自带）**：需要「带水印标定图 + 同图干净版」两张参考，输出更干净但要备料。
3. **生成时规避**：prompt 让右下角落在暗区/复杂纹理区（不保证成功，优先级最低）。

## 五、i2v prompt 模板（生成视频时写，比生图多"运动"）

```
[上面那张图的场景与主体] +
camera: [slow push in / orbit left / crane down / whip pan / dolly zoom] +
motion: [hair and shirt fluttering, steam rising, embers floating upward,
         snow blowing sideways, bubbles rising, dust drifting in the light beam] +
light: [light sweeps across face, shadow moves slowly, flicker] +
atmosphere: [volumetric haze drifting, lens flare pulsing]
```

**参考片实测的动态强度**（相邻帧像素差中位）：真动态 3–12，参考片 4–12。**太低说明图里没有可动元素，重生图；太高（>15）通常是剧烈形变，也会崩。**

## 六、下一批生图执行建议

1. **先出 6 张验证**：火焰/赛博/冰川/黑金/实验室/废墟 各 1 张，验「可动元素是否明显」「画风是否统一」
2. 画风必须**全批统一**（本司 2D 厚涂动漫画风，prompt 里每条都带 `2D thick-paint anime style`）
3. 通过后再批量出（每条片 10–15 张，生图约 12 积分/张）
4. 出图阶段就把**可动元素**写进 prompt —— 这是 i2v 能不能出好片段的决定因素

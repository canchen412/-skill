# 字幕重点字动效模板（caption_fx）

> 2026-10-13 产出，源自 ai_caption_video（GitHub）风格的两个复刻 Demo。
> 用途：口播视频里的「重点字高亮 + 动效 + 音效」字幕片段，可直接改文案复用，也可当效果参考。

## Demo A：大字报关键词高亮

- 结构：四句文案同位切换（grid 叠层），每句 2.1s
- 关键词：金色 `#FFC400` + 红色错版阴影，弹出缩放 1.32 倍，顶部弹「重点」红标签
- **改文案**：`.line.l1~l4` 里的文字，重点字包进 `<span class="kw kN animated">词<i class="tag animated">重点</i></span>`
- 时间轴（animation-delay 都是页面绝对秒）：
  - 行入场：`.05 / 2.15 / 4.15 / 6.15`（行间周期 2.1s）
  - 关键词弹出：`.95 / 3.05 / 5.05 / 7.05`
  - 行退场：`1.95 / 3.95 / 5.95`（l4 不退场）

## Demo B：逐字卡拉OK + 重点章

- 结构：逐字填充（灰米 `#CFC4AC` → 墨黑 `#1A1A1A`，steps 跳变），间隔 0.12s/字
- 重点字：填充为红 `#D8331F` + 弹跳 1.45 倍；结尾 6.0s 盖「重点是：纯度」印章（ Overshoot 缩放入场）
- **改文案**：每个字一个 `<span class="ch cN animated">字</span>`（重点字用 `chk`），按 `.kl1 .cN{animation-delay:Xs}` 排填充时刻表
- 音效点：pop @0.40 / pop @3.34 / whoosh @2.90 / dong @6.00

## 出片流程（html-motion-to-video 链路）

```bash
# 1. 逐帧截图（1080p 横屏 30fps）
node ~/.workbuddy/skills/html-motion-to-video/scripts/capture.mjs \
  --html assets/caption_fx/demoA_dazibao_16x9.html \
  --out /tmp/fxA --fps 30 --dur 8.4 --w 1920 --h 1080 --port 9413

# 2. 合成视频 + 混音（Demo A 音效轨示例）
ffmpeg -y -framerate 30 -i /tmp/fxA/f%04d.jpg -i sfx/mix_a.wav \
  -c:v h264_videotoolbox -q:v 75 -pix_fmt yuv420p -movflags +faststart \
  -c:a aac -b:a 192k -shortest out.mp4
```

音效混音（adelay=毫秒，改时间点只动这些数字）：

```bash
ffmpeg -y -i pop.wav -i whoosh.wav -i dong.wav -filter_complex \
"[1:a]asplit=4[w1][w2][w3][w4];\
[w1]adelay=0:all=1[w1d];[w2]adelay=2100:all=1[w2d];[w3]adelay=4200:all=1[w3d];[w4]adelay=6300:all=1[w4d];\
[0:a]asplit=3[p1][p2][p3];[p1]adelay=950:all=1[p1d];[p2]adelay=3050:all=1[p2d];[p3]adelay=5050:all=1[p3d];\
[2:a]adelay=7050:all=1[dg];\
[w1d][w2d][w3d][w4d][p1d][p2d][p3d][dg]amix=inputs=8:normalize=0,alimiter=limit=0.95,apad=whole_dur=8.4,aformat=channel_layouts=stereo[a]" \
-map "[a]" -t 8.4 mix_a.wav
```

## 踩坑备忘（2026-10-13 实测）

1. 多行字幕切换必须 `grid-area:1/1` 叠层同位，否则每句垂直位置漂移
2. mask（overflow:hidden）内放凸出小标签，clip padding-top 要给到 1.5em，否则标签被裁
3. 字号上限：一行 12–13 字时 16:9 用 ≤80px、9:16 用 ≤76px，超了会横向出屏
4. 页面必须满足定格契约：`window.setTime(t)` + `window.__ready`（capture.mjs 靠这两个工作）
5. 改完抽帧目检入场中途帧（t=入场开始+0.1s）看 mask 裁剪是否正常

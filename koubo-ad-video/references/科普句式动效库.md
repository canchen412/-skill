## 三、★★ 密度铁律（2026-10-14 成片实测后确立，最高优先级）

> **灿爹原话**：「科普段的动效太密了，看起来就像把下面的字幕重新做了一遍效果加到上面，
> 最多出现一行或者两行字，不然就像字幕长在了画面中一样太密。」

**根因不是动效不好，是同一句话被说了两遍。**
观众注意力被拆到三层（动效层 / 字幕层 / 画面），每层都看不清。

### 三条硬规则

| # | 规则 | 反例（v1.0 首版踩过）| 正例（v1.1 修正） |
|---|---|---|---|
| ① | **同一时刻屏幕上最多 1–2 行大字** | 开头 2 行 + 黄标；Highlight 3 行；WordPop 10 字 | 开头 1 行；Highlight 2 行；WordPop 3 字 |
| ② | **动效层只说关键词，不重复字幕完整句** | 动效写「练得少真不是原因」+ 字幕也写一遍 | 动效只挑「练得少」划掉；字幕说完整句 |
| ③ | **补充说明类内容一律不上画面** | 「我以前的活例子」做成黄标 | 删除，那是口播内容不是画面内容 |

### 职责划分（关键）

```
字幕层 = 唯一承载「完整句」的地方
动效层 = 只做「指认」，挑 1–2 个词
画面层 = 提供情境，不承担文字信息
```

★ **判断标准**：如果动效层的文字和字幕层的句子读起来是同一句话，就是重复了，删掉动效那层。

### 密度自检表（出片前逐项过）

- [ ] 每个动效镜位的屏幕上文字 ≤ 2 行？
- [ ] 动效层的字是否和字幕重复？
- [ ] 有没有「补充说明」被做成画面元素（应该只在口播里）？
- [ ] 同一时刻画面上是否有两个以上大字块？

## 四、spec 写法

文案旁放同名 `.fx.json`，加 `explains` 数组：

```json
{
  "explains": [{
    "kind": "mark",
    "phrase": 7,
    "anchor": "练得少真不是原因",
    "x": 200,
    "y": 270,
    "durSec": 7.1,
    "fontSize": 62,
    "lineGap": 132,
    "stagger": 78,
    "lines": [
      {"text": "练得少", "kind": "strike", "color": "#E8796A"},
      {"text": "微量元素长期没补", "kind": "marker", "color": "#D4FF00"}
    ]
  }]
}
```

| 字段 | 必填 | 默认 | 说明 |
|---|---|---|---|
| kind | ✓ | — | 固定 `mark` |
| lines | ✓ | — | **最多 2 行**（密度铁律）；每行 `{text, kind, color}` |
| lines[].kind | ✓ | — | `strike` 划掉 / `marker` 荧光笔 / `underline` 下划线 |
| lines[].color | | strike→`#E8796A`、其余→`#D4FF00` | |
| anchor | 建议 | text | **配音实际读的词**（防同词跨镜错锚） |
| phrase | 建议 | 0 | 第几镜起（1 起始） |
| x, y | ✓ | — | **左上角** x、第一行**中心** y |
| durSec | ✓ | — | 停留时长，≥1.2s |
| lineGap | | 132 | 行间距 |
| stagger | | 78 | 行间入场错开（帧），拉开让观众逐行读 |
| fontSize | | 62 | |

`make_fx_spec.py` 归并进 `explain` 数组，与 `viz` 同一渲染链。
⚠️ `explains` 的锚定分支尚未写，当前需手写 spec。

### 三种 kind 的语义分工

| kind | 用于 | 观感 |
|---|---|---|
| `strike` | **否定**某个说法（错的、过时的、误解的） | 一道红杠划掉 |
| `marker` | **肯定**某个说法（正确的、关键的） | 荧光笔从左擦出 |
| `underline` | 中性强调（不否定也不肯定） | 下划线画出 |

## 五、落位铁律（必须实测，别凭感觉）

**先用 Canny 边缘密度打分，再定坐标。** 用法同 `pick_kw_pos.py`：

```python
edge = cv2.Canny(cv2.cvtColor(img, cv2.COLOR_BGR2GRAY), 60, 160)
score = edge[y-hh:y+hh, x-hw:x+hw].mean()   # 低 = 平 = 不压主体
```

判据：**边缘密度 < 6 才可用**；`y + 字高 > 880` 一律排除（侵入字幕带）。

### 常用素材的实测结果（2026-10-14）

| 素材 | 好落位 | 差落位（原因）|
|---|---|---|
| 餐食_木桌餐具摆台_中景 | 左侧 (500,430)=3.73 / 右侧 (1520,450)=1.35 | 正中 (960,562)=11.92 压人物 |
| 该图特征 | 上 1/3 均值 45（极暗）→ **亮字放上部** | 下 1/3 是餐桌面 136（最亮）→ 浅色字会糊 |

**通用规律**：
- 动漫/实拍底片**上暗下亮**（人物占中上部，桌面/地面占下部）⇒ **亮色字往上放**
- 人物主体区（约 x 680–1300 / y 180–700）**禁放任何字**
- 多个动效同镜位时要**时间互斥**，留 0.15s 呼吸
